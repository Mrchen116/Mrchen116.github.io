1 · 全景鸟瞰：六个时代

LLM 的十年，是把人类完成一件事所需的每一个动作——举例、分步思考、查资料、用工具、复查、调度他人——逐个内化进系统的过程。每内化一环，能力上一个台阶，瓶颈也随之上移一层。

3 · 演进逻辑：痛点 → 突破 → 新瓶颈

3.1 主链：补全 → Chat → CoT → 工具 → Agent → Agent 群

图 2 · 主链演进

箭头上的文字是"上一代无法解决的痛点"，正是它催生了下一环。

阶段上一代无法解决的痛点该技术如何突破引入的新瓶颈
补全（GPT-2/3）每个任务都要单独微调，标注昂贵ICL：上下文给示例即可适配任意任务提示脆弱、结果不稳、上下文长度受限；用户不知道"该怎么问"
Chat（InstructGPT→ChatGPT）模型续写而非回答，不听指令、不安全Instruction Tuning 学格式，RLHF 学偏好对齐税（能力被磨平）、奖励黑客、谄媚倾向、标注成本高
CoT（2022→o1）多步推理一步到位必错；提示词里的 CoT 是"表演"不是"能力"先显式写出步骤（CoT）→ 再用 RL 把"想得久"训进权重（o1/R1）延迟与成本随思考长度线性上升；思维链不可审计；只在可验证域收益最大
工具（ReAct→Function Calling→MCP）推理再强也不知道今天的股价、改不了本地文件ReAct 交错推理与行动 → Function Calling 变成 API 原语 → MCP 消除 N×M 集成工具描述污染上下文；提示注入成为一等安全问题；server 质量参差与供应链风险
Agent（Devin→Claude Code→Codex）单轮工具调用只能干一件小事，干不完一个任务把"循环 + 文件系统 + shell + git"给模型，允许它自行迭代到完成可靠性复利：每步 95% × 20 步 = 36%；上下文腐化（context rot）；成本失控；错误累积无人发现
Agent 群（多 agent / ultra / swarm）单 agent 上下文有限、串行太慢、单点失败orchestrator-worker：主 agent 拆解，子 agent 各带独立上下文并行，压缩后回传token 用量约 15×；子 agent 之间信息不共享导致决策冲突；编排本身成为需要调试的软件
关键争论（务必并列呈现）：2025 年 6 月 Anthropic 公布多 agent 系统内部评测比单 agent 高 90.2%，同月 Cognition 公开主张"别做多 agent，用单线程线性 agent + 完整上下文共享"。到 2026 年，实践给出的答案是分场景：研究/搜索类任务（可并行、结果可合并）适合多 agent，编码类任务（强依赖、上下文需共享）更适合单主线 + 隔离 worktree。GPT-5.6 的 ultra 与 Meta 的 Contemplating Mode 表明，多 agent 正在从"应用层编排"下沉为"模型侧的推理时基础设施"。

3.2 支链 A：对齐链 —— 谁来给信号

SFT（人写答案） → RLHF（人排序偏好，2022-03） 痛点：写答案太贵 新瓶颈：奖励黑客、标注不可扩展 → CAI / RLAIF（AI 按原则自评，2022-12） 痛点：人标不可扩展 新瓶颈：原则由谁定、评判模型偏置被放大 → DPO（免奖励模型，2023-05） 痛点：PPO 不稳且重 新瓶颈：离线数据受限、易过拟合偏好集 → RLVR（验证器给二元奖励，2024-11） 痛点：奖励可被刷分 新瓶颈：只覆盖可验证域 → GRPO / R1（纯 RL 涌现长 CoT，2025-01）痛点：CoT 标注贵 新瓶颈：可读性差、语言混杂 → Agentic RL（环境即数据，2025-2026） 痛点：单轮奖励不够 新瓶颈：奖励信号坍缩、turn 级信用分配
2026 年的实证边界：清华团队 ICLR 2026 工作扫描 11 个模型 × 5 种内在奖励，发现无监督 RLVR 普遍"先升后崩"（rise-and-fall），必须转向外部可验证奖励才能持续 scaling；ACL 2026 另一项 63 组对照实验建立 RL 后训练幂律，发现 32B 参数后边际收益递减。⚠️ 两项均为单一来源，建议以原文复核。

3.3 支链 B：知识链 —— 上下文里该放什么

参数化知识（知识锁在权重里，改不动、会过时、会幻觉） → RAG（2020-05） 外挂知识、可溯源 新瓶颈：检索质量即上限，chunk 割裂语义 → HyDE / GraphRAG（2022-2024）解决语义不对称与全局归纳 新瓶颈：建图成本高、更新代价大 → Agentic RAG（2025） 检索变成多步决策 新瓶颈：token 与延迟激增、可控性下降 → Context Engineering（2025-06 术语 / 2025-09 Anthropic 官方定义） 定义："在 LLM 推理过程中策划并维护最优 token 集合的策略集" 四杠杆：Write（外置笔记）/ Select（即时检索）/ Compress（压缩）/ Isolate（子 agent 隔离） 实证：context editing + memory tools 组合带来 39% 性能提升；100 轮网页搜索 token 降 84% 新瓶颈：注意力预算有限（context rot）、记忆陈旧与投毒
反直觉结论：2026-06 的 Less Context, Better Agents 系统证明，长程 agent 中剪枝上下文优于保留全历史——1M 上下文的意义不是"全塞进去"，而是"塞得起，但仍要选"。

3.4 支链 C：抽象层上移 —— 人负责的东西在变

这是本文认为最具解释力的一条主线。四层是嵌套关系，不是替代关系：

图 3 · 抽象层四级上移（核心主线）

图例：Prompt Context Harness Loop。四层嵌套而非替代；每突破一层瓶颈，"人该操心什么"就被推高一层。

层时期人负责什么触发它的瓶颈
Prompt Engineering2022–2024写好一句话模型听不懂意图
Context Engineering2025策划一个窗口的信息模型懂意图了，但不知道现场情况
Harness Engineering2026 初设计包住模型的那套软件（工具、hooks、验证器、记忆、沙箱）模型知道现场了，但一次跑不对
Loop Engineering2026 中设计那个会自动提示 agent 的循环（trigger/state/worker/verifier/reviewer/exit rule）单次能跑对了，但每次都要人按开始键

公式化表达：Agent = Model + Harness（Böckeler / martinfowler.com）；System = Loop(Agent, Verifier, Exit Rule)。

Hashimoto："每当你发现 agent 犯了一个错，就花时间工程化一个解决方案，让它不会再犯同样的错。"
Osmani 给 loop 层留了一个警告：没有客观停止条件的 loop 就是"一台昂贵的无限重试机"，而人类可能退化为"点开始键的人"。
出处提示：Harness Engineering 一词的"首创者"有 Mitchell Hashimoto（2026-02-05 个人博客）与 Matt Kropp（BCG）两说，无决定性证据；本文采信"2026 年初多方几乎同时提出，OpenAI 2026-02-11 官方文使其定型"。

3.5 支链 D：架构链 —— 怎么把成本压下去

图 4 · 架构进化链

成本下降的物理路径：从全参数稠密到稀疏 MoE，再到压 KV Cache 的 MLA、降复杂度的 DSA、混合线性，最后叠加极致稀疏与低精度（并顺带适配国产芯片）。MiniMax M2 退回全注意力是该链路的已知反例。

Dense Transformer（O(N²) 注意力 + 全参数激活） → MoE（2017 提出 / 2023-12 Mixtral 开源验证） 激活比从 100% 降到约 25% → MLA（DeepSeek-V2, 2024-05） 压 KV Cache，直接引爆国内价格战 → 稀疏注意力 DSA（DeepSeek V3.2, 2025-09） O(L²) → O(L·k)，128K 解码单价降约 2/3 → 混合线性注意力（2025-2026） Qwen3-Next / Kimi Linear / MiniMax / 蚂蚁 Ring-2.5-1T（1:7 混合，万亿参数级验证） → 极致稀疏 + 低精度（2026） Kimi K3 激活 16/896（约 0.6%）； DeepSeek V4 mxFP4；Kimi K3 MXFP8 QAT
必须记录的反例：MiniMax M2（2025 年末）退回全注意力，团队称线性注意力在推理与多轮任务上精度不佳。这说明混合线性路线尚未定论，2026 年蚂蚁 Ring-2.5-1T 在万亿量级的成功是目前最硬的正面工程证据，但仍非终局。

低精度（mxFP4/MXFP8）在 2026 年还有一层地缘含义：它同时是适配国产芯片的路径——DeepSeek V4 首次披露在英伟达 GPU 与华为昇腾 NPU 上验证细粒度专家并行。

5 · 五条发展规律

规律一：Scaling 的支点每 2–3 年迁移一次，但总投入从未下降

2020–2022 预训练参数（Kaplan）→ 预训练数据（Chinchilla） 2022–2024 后训练对齐（RLHF/DPO） 2024–2025 推理时算力（o1 test-time scaling） 2025–2026 后训练 RL 算力（DeepSeek V3.2：RL 算力 > 预训练的 10%） 2026– Agent 循环时算力（多 agent 并行 / 长任务 / ultra 模式）

每次"某某 scaling 撞墙"的论调出现后，新的支点就会接管增长。Ilya 在 2024 年底说"预训练将终结"，同时点名的三条出路（agents、合成数据、inference-time compute）在其后 18 个月内全部兑现。

推论：不要问"scaling 是否还有效"，要问"下一个支点在哪里"。

规律二：每一次能力跃迁，都是把人类工作流的某一环内化进系统

人类的动作被内化的时间内化形式
举例说明2020In-Context Learning
分步思考2022 → 2024CoT（提示层）→ o1/R1（权重层）
听懂偏好2022RLHF / CAI
查资料2020 → 2025RAG → Agentic RAG
用工具2022 → 2024ReAct → Function Calling → MCP
复查与返工2023 → 2026Reflexion → Verifier / 自验证回路（Opus 4.7 的 Plan→Execute→Verify→Report）
按方法做事2025Agent Skills
调度他人2025 → 2026多 agent → GPT-5.6 ultra / Meta Contemplating
按开始键2026Loop Engineering
推论：想预测下一个突破，就问"人类在这个流程里还剩哪个动作没被内化"。目前剩下的主要是：定义什么值得做、判断结果好不好、承担后果。

规律三：可验证性决定进步速率——加速是真实的，但是域特异的

Epoch AI 2026-04-16 给出目前最严谨的裁决：4 个能力指标中 3 个显著加速，最佳拟合是"推理模型 / 非推理模型两条独立趋势"，推理模型带来一次性跃升 + 2–3 倍更快的斜率；但第 4 个指标（资源受限的 WeirdML V2）完全无加速。

原因链条清晰：RLVR 只在有确定性验证器的域奏效 → 编程与数学天然可验证 → 这两个域获得 RL 加持 → 其余域只能吃预训练与蒸馏的余荫。这解释了 AI Index 2026 观察到的"锯齿状能力"：网络安全任务 93%，而认读模拟时钟只有 50.1%。

推论：一个任务能被 AI 快速攻克的先决条件，不是它"难不难"，而是它"对错好不好判定"。

规律四：成本坍缩是常量，能力以"同价加量"交付

固定能力的推理价格以约 40×/年（每 2 个月减半）坍缩，这不是竞争策略，而是算法效率（3×/年）× 硬件性价比（1.37×/年）× 架构创新 × 精度下降叠加的物理规律。

对应的商业表达是：旗舰价格档位长期稳定，而同价位的能力持续加码。Anthropic 的 Opus 档从 4.5 到 4.8 到 Opus 5 一直是 $5/$25，但 Frontier-Bench 性能翻倍以上；GPT-5.6 Luna 发布 20 天后直接降价 80%。唯一的例外：GPT-5.5（2026-04）把旗舰价从 $2.50/$15 提到 $5/$30，是近年罕见的逆向定价。

规律五：瓶颈持续上移，抽象层随之上移

瓶颈在模型听不懂 → 人做 Prompt Engineering 瓶颈在模型不知现场 → 人做 Context Engineering 瓶颈在单次跑不对 → 人做 Harness Engineering 瓶颈在每次要人启动 → 人做 Loop Engineering 瓶颈在【下一个】 → ?

关键实证：swebench.com 统一 harness 下同一模型的分数比厂商自报低约 5 个百分点；GAIA 上带脚手架 74.6% vs 裸模型 44.8%（同题 30 分的脚手架差）。在 2026 年，"用什么模型"对结果的影响，已经小于"用什么 harness"。

补充规律（半条）：开放与闭源的差距稳定在 3–6 个月，但供给的地理重心已经迁移。Epoch 测得开放权重模型落后前沿闭源 4 个月 / 8 个 ECI 点（2026-05），较 2025-10 的 3 个月略有扩大。但结构变了：Meta 在 2026-04 退出前沿开源，而 DeepSeek / Kimi / GLM / Qwen / MiniMax / 蚂蚁成为全球开放权重的主要供给方；2026-07-24 微软、英伟达、Hugging Face 等美国企业联合声明支持开放权重。
